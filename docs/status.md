# Status and roadmap

HammeRR is in active development.

- **The editor** is usable today for building, texturing and wiring up brush-based maps, by hand or with an AI agent.
- **The compiler is experimental.** Compiled maps load and play in Counter-Strike: Source. Fast and Detailed visibility are available; lighting covers direct light, sky ambient and up to four optional diffuse bounces; HDR remains unfinished.

## Editor

| Area | State |
| --- | --- |
| AI access | Shared Session operations serve desktop HTTP MCP and private stdio MCP. `hammerr-headless` builds independently of the Slint UI; editing and compilation leave graphics uninitialized until rendering is requested. |
| Opening and saving VMFs | Works. Imported properties and extra blocks are retained; saves increment the map version and use standard VMF formatting. File symlinks and target permissions are retained; broken or looping save links are refused. Round trips through other editors haven't been verified yet. |
| Recent maps | Up to twenty paths retain compatible build settings, with shared reopen, remove and clear controls. Game content and custom FGD files do not switch automatically; automatic relocation and coordinated writes from multiple editors are unavailable. |
| Cut, copy and paste | Shared capture, guarded Cut, detached cross-map payloads, native VMF text and owned Paste previews work for bounded whole-object sets. Native group ancestors, owned-brush notes, terrain and exact internal links transfer. Native layer ancestry and owned-brush memberships transfer with independent IDs. Private Hammer clipboard formats, component copies and saved partitions are unsupported. |
| Prefab library | Named portable VMF assemblies share save/search/inspection, centered Paste previews, safe IDs/links/groups/layers/notes and separate library deletion. Assets stay external; thumbnails, direct replacement/renaming and rotated/scaled placement are unavailable. |
| Layers | Native nested layers support names, colors, reparenting, multiple memberships, exact selection, shared undoable map hide/show and clipboard transfer. Automatic categories and separate editor-only filters are unavailable. |
| Object groups | Native nested groups for world brushes and whole entities support membership/name/parent edits, group selection, temporary bypass and Undo. Imported entity-owned child-brush memberships are preserved but cannot be edited; malformed group graphs cannot be authored. |
| Brushes, transforms and shapes | Works. Rigid grid snapping previews the combined selection bounds minimum and shares Apply/Cancel. Explicit real-corner snapping uses shared surface placement; magnetic snapping and pivot-setting tools remain unavailable. |
| Overlapping selection | Alt+click and shared MCP operations cycle depth-ordered objects, brush owners and native groups, with model triangle picking and the same visibility rules as ordinary selection. The nearest 64 distinct hits are available; persistent selection filters and separate solid/group modes are planned. |
| Polygon brushes | Convex and simple concave outlines, grid/exact corners, axis-aligned extrusion, materials and shared previews/Undo work. Oblique drawing planes and holes are planned. |
| Surface placement | Shared floor/ceiling and picked-surface previews, mesh/terrain contact, normal alignment, offsets and one-step Undo work. Explicit corner snapping translates one brush owner from a chosen real vertex to the nearest corner of the first visible flat brush face. Model/terrain vertices, multiple-owner corner snapping, magnetic snapping, independent settling and overlap/physics resolution remain unavailable. |
| Repeated placement | World and source-local translation/rotation/brush-scale arrays share previews, one captured original frame, unique generated names, checked internal-reference remapping and one-step Undo. Uncertain internal links and named source sets with scripts or dynamic I/O reject; point/model scale arrays and surface sprinkle are unavailable. |
| Hollow, carve and clip | Works for brushes. Terrain is rejected. |
| Merge brushes | Guarded previews join 2–16 brushes into one convex brush, retaining outer face settings and one-step Undo. World brushes or children of one brush entity can merge; gaps, concave unions, mixed owners and terrain reject. |
| Vertices, edges and faces | Brush component editing works. Terrain has separate vertex controls. |
| Flat partitions | Works. Per-piece materials, scale/shift/rotation, Fit and horizontal/vertical justification share owned plans and Undo. Inward extrusion, free-form dividing lines and new texture axes are planned. |
| Materials and textures | Works. Failed asset discovery and material reads report errors; failed catalogs can be retried after content repairs. |
| Asset reload (P11) | Partial. **Reload material assets** and MCP refresh cached VMT/VTF display data, sky faces and the material catalog through existing mounts, preserving map data, history and draft geometry. Cached model material candidates are resolved again without replacing geometry; particle definitions have a separate reload. File watching, remounting, FGD refresh and running-game caches remain unavailable. |
| Working region | One temporary whole-object box shares desktop/MCP display and spatial filtering, paginated visibility reasons and reachable Clear. Saved visibility, source/history and build scope stay independent. Draw distance and arbitrary filter rules are unavailable. |
| Fog preview | Explicit authored controller choice and static linear nonradial fog work in perspective Textured views. Invalid shared choices report issues without fog; unsupported modes, transitions, runtime I/O and native visual parity remain outside the preview. |
| Particle effects | Active mounted manifests and binary-2/pcf-1 definitions support search, metadata inspection, reload and owned effect-name choices. Particle animation, viewport rendering and map-specific manifests are unavailable. |
| 2D sky preview | Six mounted static LDR faces render through authored sky surfaces in perspective Textured views, with shared controls and load diagnostics. Axis-aligned texture scale/translation and unequal face sizes work. 3D sky-camera regions, HDR, sky fog, exposure, animation and compiled visibility fidelity are unavailable. |
| Entities, connections and renaming | Works. |
| Map checks | Geometry, IDs, textures, entity logic, asset paths, face-linked material/texture errors, terrain metadata and authored spawn clearance against static brushes/world/detail terrain. Models, compiler LOD changes, runtime placement, objectives, full dependencies and engine limits are planned. |
| Terrain (displacements) | Creation, chosen corners, resolution edits, sculpting, blend paint, full/half-edge and corner-only sewing across grid resolutions and collision/border-shading controls and per-triangle walkability/buildability work with guarded previews and Undo. Viewport center picking and framing follow displaced terrain. Native triangle subsets retain checks across surfaces, with viewport picks, yellow outlines and framing. Retained triangle unions or exact checked vertices can mask sculpting and blend edits, with cyan vertex guides, picking, framing and box selection. Volume/marquee matching follows actual sheets, and volume boxes select native triangle subsets. Indexed paint/texture strokes also pick displaced surfaces instead of parent boxes. Compatible mixed-power full and whole-to-half edges compile with native LOD masks and snapping. Live sculpt/blend strokes share bounded paths, masks, radius guides, owned review and one-step Undo. Exact world XYZ vertex movement and viewport axis/plane/screen handles share owned previews, masks, grid snapping and Undo. Connected full-edge base-cage subdivision generates editable rounded grids. Half-edge cage subdivision, other partial spans and restricted-topology remapping remain planned. |
| Models | Searchable folder/used groups, isolated model/skin previews and one-step Apply/Cancel share Session/MCP. Static meshes and checked reference poses draw with materials, skins, Source origins/angles, selection and hiding; inspection/reload, mesh picking, bounds-based marquee/volume matching, object reports, framing and local transform bounds work. Named bodygroups share previews, atomic Apply/Undo and selectable helpers for blank choices. Local attachment names and reference-pose world positions/axes have shared inspection, owned guides and framing; animated/virtual attachments and attachment parenting remain planned. Animation playback, procedural/IK poses, scaling and opacity/render-mode overrides remain planned. Dynamic-model RGB tints share color controls, viewport/MCP rendering and alpha-preserving Undo; colored static props are rejected by the current writer. |
| Sounds | Mounted WAV/MP3 search, folder/script/used groups, manifest sound-script metadata and wave variants, isolated audition/volume, agent audio export and atomic sound-field choices work through shared Session/MCP operations. Game mixing, soundscapes, voice/sentence synthesis, map-specific overrides and ambiguous script resolution are planned. |

## Next

**Editor:** broader clipboard formats and metadata transfer, free-form flat partitions, inward extrusion, new partition texture axes, terrain clipping and authoring, broader model formats and poses and broader map checks.

**Compiler:** HDR, broader physics collision, broader terrain topology, prop lighting, brush-model overlays and water transitions.
