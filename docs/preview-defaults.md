# Preview defaults

Choose which images and guides appear at startup.

1. Set **Selection outlines**, **Selection tint**, **Selection bounds**, **Authored models**, **Sprite resources**, **Entity helpers**, **Entity images** and **Entity model guides** under **Overlays**.
2. Set **Rope preview** and **2D sky preview** as required.
3. Choose **Edit → Preferences → Preview defaults…**.
4. Click **Save current as defaults**.

Use **Apply saved defaults** to apply them now.
Use **Reload defaults** after an outside file change.
Use **Reset saved defaults** to save factory values.
See [Saved defaults](basics.md#saved-defaults) for storage errors.

## Limits

- Only these ten switches are stored.
- Factory values enable outlines, selection tint, authored models, sprite resources, entity helpers, entity images and model guides. Selection bounds, rope and sky previews start disabled.
- Cameras, fog, sky exposure and viewport modes are separate.
- Ordinary viewport changes do not change saved defaults.
- Applying defaults requires finished previews and owned work.
