# Fly speed and navigation defaults

Set camera flight speed without changing the map.

1. Enter **Fly speed** under **Viewport**.
2. Press Enter.
3. Hold the right mouse button to fly with WASD/QE.

Accepted speeds are 25–20,000 units per second. The factory speed is 600.
Shift gives four times the current speed.
Scroll while flying to adjust the same setting.

## Save the speed

1. Open **Navigation defaults…**.
2. Click **Save current as defaults**.

Use **Apply saved defaults** to restore saved speed now.
Use **Reload defaults** after an outside change.
**Reset saved defaults** saves the factory speed; apply it separately.
See [Saved defaults](basics.md#saved-defaults) for storage errors.

## Limits

Only flight speed is stored. Camera position, orientation, zoom and saved views are separate.
Ordinary speed changes remain temporary.
